# Spec Delta

## ADDED Requirements

### Requirement: 检索响应提供可追溯审计标识

每次登录用户调用知识检索接口时，系统 MUST 持久化该操作的审计轨迹，并在成功响应中返回唯一 `audit_id`。该轨迹 MUST 记录认证班级内的命中标识、名次、检索模式/分数和时间，包括空命中状态；不得记录切片正文或向量 payload。此标识只用于审计定位，不得改变原检索结果、权限边界或引用来源格式。

#### Scenario: 成功检索返回审计标识
- **WHEN** 已登录用户调用 `/api/knowledge/search` 并得到命中或空结果
- **THEN** 响应包含对应的 `audit_id` 且该标识可由管理员审计 API 定位
- **AND** 审计轨迹仅记录本次认证班级的结果

#### Scenario: 未认证或失败的检索不泄露审计信息
- **WHEN** 未登录用户请求知识检索，或检索依赖失败
- **THEN** 系统继续使用既有 401/503 响应契约
- **AND** 响应不泄露任何审计记录或其他班级的命中信息
