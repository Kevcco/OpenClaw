# Proposal

## Why

当前材料工作区的搜索只匹配材料标题，而知识库正文尚不能按主题查找；教师和学生因此难以从本班材料中定位具体知识内容。第 4 课需要补齐班级范围内的混合检索与可核验来源，让每条命中都能回到原始教研材料。

## What Changes

- 新增受登录保护的知识库检索能力，结合关键词匹配与语义相似度查找本班材料内容。
- 将材料内容按可定位的片段建立索引，并在新增、删除及索引重建时维护索引和来源元数据。
- 检索结果展示命中片段和材料来源，提供回到本班材料预览或下载的入口；扩展现有工作区搜索体验。
- 检索范围始终由服务端会话班级确定；本变更只返回检索结果，不生成答案或开展对话。

## Capabilities

### New Capabilities

- `knowledge-retrieval`: 班级范围内的混合知识检索、结果片段展示、来源追溯和索引生命周期。

### Modified Capabilities

无。现有 `auth-upload` 是已完成变更中的历史 delta，本次新增独立检索能力，不回改该变更。

## Impact

预计影响 Flask 知识库/材料 API、SQLite 数据结构和迁移或重建流程、检索索引及其持久化配置、材料工作区前端与回归测试；如采用向量存储，也会影响 Python 依赖及 Docker Compose 数据卷配置。既有 `.txt`/`.md` 上传和角色授权行为保持不变。
