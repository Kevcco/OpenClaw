# Spec Delta

## MODIFIED Requirements

### Requirement: 有依据后生成带引用的简短回答

系统 MUST 提供受保护的 `POST /api/ask`，并将其作为单次问答的兼容入口。接口只使用本轮最新问题发起本班混合检索，最多取前 4 个切片；历史对话可作为上下文，但客户端提供的 `system` 或 `developer` 消息 MUST 被丢弃。回答生成前 MUST 读取当前班级已保存的助手提示词和“解题引导”技能开关；提示词和技能规则 MUST 由服务端注入，客户端不得覆盖。只有检索到切片后，系统才可调用服务端回答网关。回答中的 `[1]`、`[2]` 等编号 MUST 与返回的 `citations` 顺序一致，回答网关不得获得向量分量、Qdrant 原始点数据或其他班级内容。本课新增的连续会话接口 MUST 复用相同的检索、提示词、技能和引用规则，但以 SSE 增量事件返回并持久化每轮消息。

#### Scenario: 有依据时回答并标注引用
- **WHEN** 用户提问命中本班至少一个切片
- **THEN** 系统将当前班级提示词、启用的解题引导规则及最多 4 个切片交给回答模块
- **AND** 响应包含简短回答和按 `[1]` 等编号排列的 citations，编号顺序与出处列表一致

#### Scenario: 无依据时不调用回答模型
- **WHEN** `/api/ask` 或会话消息的本班混合检索没有命中切片
- **THEN** 接口返回固定未找到回答和空 `citations`；SSE 流发送完成事件而不发送虚构正文
- **AND** 系统不调用回答网关
